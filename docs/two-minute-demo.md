# Document Agent 两分钟演示脚本

这是一份录屏和面试现场共用的操作脚本。当前仓库不声称存在公网演示地址。

## 0:00–0:20：说明问题

打开工作台首屏，用一句话说明：企业文档处理不是一次问答，而是一条需要可追踪、可审批、可复核的工作流。

## 0:20–0:45：创建任务

上传 `samples/contract_sample.txt`，选择 `Contract Review Memo`，点击“开始处理”。指出本地无模型 Key 时使用确定性规则路径，因此面试现场也能完成演示。

## 0:45–1:10：查看 Agent 证据

在任务详情中展示：

- 结构化字段与风险异常；
- Agent 工具链及每一步耗时；
- 生成的 Markdown、DOCX 和 PDF 产物。

## 1:10–1:30：人工审批与版本

补充一个人工修订字段，展示结果版本增加，再从审批队列通过任务。打开审计面板说明谁在何时做了什么操作。

## 1:30–1:50：RAG 引用

在 RAG 面板提问“这份合同的付款方式和违约责任是什么？”，展示回答与引用片段。强调负查询也在离线评测中单独计算拒答率。

## 1:50–2:00：收束

打开生成的[抽取评测报告](evaluation_report.md)和[RAG 评测报告](rag_evaluation_report.md)，说明公开数据为隐私安全示例，指标由脚本和 CI 生成，不是手写结果。

## 演示边界

- 当前没有公网托管演示。
- 公开样本不包含真实客户、订单或合同数据。
- 本地 RAG 是轻量检索实现，用于证明工作流和评测边界，不宣称等同生产向量检索规模。
